## 一、引言

#### 1.1 编写目的

本文档为《智核私有舱（个人RAG模型）》软件的详细技术说明书，面向大赛评审专家、指导教师及项目开发团队。本文档旨在说明系统的功能设计、技术架构、创新特色及使用方法。

#### 1.2 项目背景

随着大语言模型（LLM）技术的快速发展，检索增强生成（RAG）已成为企业知识管理、个人学习辅助的重要技术手段。然而，现有的RAG系统大多依赖云端服务，存在数据隐私泄露风险、知识库更换困难等问题。

本项目基于阿里云通义千问大模型，设计并实现了一个面向个人用户的本地化多模态RAG系统，核心优势在于：
- **数据隐私保护**：所有文档存储在本地，无需上传云端
- **知识库可更换**：模块化架构支持灵活切换不同领域的知识库
- **多模态支持**：支持图片OCR和视频帧分析能力

#### 1.3 开发环境

|-----|------|
| 开发语言 | Python 3.10+ |

## 二、系统概述

#### 2.1 系统定位

本系统是一个面向个人用户的**多模态知识问答系统**，通过本地知识库向量化存储和阿里云通义千问大模型，实现基于私有知识的智能问答功能。

#### 2.2 主要特性

| 特性 | 说明 |
|-----|------|
| 多格式支持 | PDF、Word、TXT、Markdown、图片（JPG/PNG/BMP） |
| 图片OCR | 提取图片中的文字内容并纳入检索 |
| 视频分析 | 提取视频关键帧进行多模态问答 |
| 智能问答 | 基于知识库内容的精准回答 |
| 桌面应用 | 一键启动的图形化界面 |
| 离线可用 | 本地化部署，保护数据隐私 |

## 三、功能模块说明

#### 3.1 文档加载模块（ingest.py）

**功能描述**：从指定目录递归加载所有支持格式的文档，提取文本内容并切分为固定大小的片段。

**支持的文件格式**：
- `.txt` - 纯文本文件
- `.md` - Markdown文档
- `.pdf` - PDF文档（通过PyPDF2提取）
- `.docx` - Word文档（通过python-docx提取）
- `.jpg/.jpeg/.png/.bmp` - 图片文件（通过OCR提取文字）

**文本处理流程**：
1. 递归遍历指定目录下的所有文件
2. 根据文件扩展名调用对应的解析器
3. 图片文件调用阿里云百炼OCR接口提取文字
4. 将长文本按500字符分块，100字符重叠
5. 返回 `(source_path, chunk_text)` 元组列表

**关键函数**：
- `read_txt()` - 读取文本文件
- `read_pdf()` - 读取PDF文档
- `read_docx()` - 读取Word文档
- `read_image_with_ocr()` - OCR图片识别
- `split_text()` - 文本分片
- `collect_documents()` - 收集目录下的所有文档

#### 3.2 向量化与索引模块

**功能描述**：将文档分片转换为语义向量，构建可检索的向量索引。

**技术实现**：
- 使用阿里云DashScope的`text-embedding-v1`模型生成1536维向量
- 向量以NumPy数组格式存储在`index_store.npy`
- 元数据（来源路径、文本内容）存储在`index_meta.npy`
- 支持增量更新和重新构建

**关键函数**：
- `build_embeddings()` - 调用API批量生成向量
- `save_index()` - 保存索引到本地文件
- `load_index()` - 加载已有索引

#### 3.3 检索与生成模块（rag_service.py）

**功能描述**：根据用户问题检索相关文档片段，调用大模型生成回答。

**检索算法**：
- 使用余弦相似度计算查询向量与文档向量的相似程度
- 返回Top-K（默认5个）最相似的文档片段

**生成流程**：
1. 用户问题转换为向量
2. 在索引中检索最相似的K个片段
3. 构建包含检索上下文的提示词
4. 调用qwen-turbo模型生成回答
5. 返回回答及参考来源

**关键函数**：
- `embed_query()` - 查询向量化
- `cosine_similarity()` - 余弦相似度计算
- `search_similar_chunks()` - 相似片段检索
- `build_prompt()` - 提示词构建
- `generate_answer()` - 答案生成
- `rag_answer()` - RAG主流程

#### 3.4 多模态分析模块

**图片OCR识别**：
- 使用`qwen-vl-ocr-latest`模型
- 支持JPG、PNG等常见图片格式
- 提取图片中的文字内容纳入知识库

**视频帧分析**：
- 使用OpenCV提取视频关键帧
- 通过qwen-vl模型分析帧内容
- 支持结合知识库进行动作指导

**关键函数**：
- `analyze_image()` - 图片内容分析
- `extract_video_frames()` - 视频帧提取
- `analyze_video_frames()` - 视频帧分析
- `multimodal_rag_answer()` - 多模态RAG主流程

#### 3.5 Web服务模块（app.py）

**功能描述**：提供RESTful API接口，支持文件上传、知识库管理、问答交互。

**主要接口**：

| 接口路径 | 方法 | 功能 |
|---------|------|------|
| `/chat` | POST | 文本问答 |
| `/vision/chat` | POST | 看图问答（带图片） |
| `/video/chat` | POST | 视频问答 |
| `/upload` | POST | 文件上传 |
| `/knowledge` | GET/POST | 知识库管理 |
| `/ocr` | POST | 图片OCR |

**技术特性**：
- FastAPI异步框架，支持高并发
- CORS跨域配置，支持前后端分离
- 自动创建上传目录和知识库目录
- 索引构建进度实时推送

#### 3.6 桌面启动器（launcher.py）

**功能描述**：提供一键启动的图形化界面，适合非技术用户。

**功能特性**：
- 一键配置API密钥
- 知识库目录选择
- 索引构建按钮
- Web服务启动并自动打开浏览器
- 端口占用检测
- 运行状态实时显示

## 四、数据流设计

```
用户提问
    │
    ▼
┌────────────┐
│  向量化查询 │  rag_service.embed_query()
└─────┬──────┘
      │ 生成查询向量
      ▼
┌────────────┐
│  相似度检索 │  rag_service.search_similar_chunks()
└─────┬──────┘
      │ Top-K个相关片段
      ▼
┌────────────┐
│ 构建提示词  │  rag_service.build_prompt()
└─────┬──────┘
      │ 带上下文的完整提示
      ▼
┌────────────┐
│ 调用大模型  │  DashScope qwen-turbo
└─────┬──────┘
      │ 生成回答
      ▼
   用户回答
```

## 五、配置管理（config.py）

系统采用配置中心化设计，所有参数集中在`config.py`：

| 配置项 | 默认值 | 说明 |
|-------|-------|------|
| `dashscope_api_key` | 环境变量 | 阿里云API密钥 |
| `llm_model` | qwen-turbo | 对话模型 |
| `embedding_model` | text-embedding-v1 | 向量化模型 |
| `ocr_model` | qwen-vl-ocr-latest | OCR模型 |
| `chunk_size` | 500 | 文本分片大小 |
| `chunk_overlap` | 100 | 分片重叠字符数 |
| `top_k` | 5 | 检索返回数量 |

## 八、使用说明

### 8.1 快速开始

1. 双击运行 `dist/RAG启动器.exe`
2. 如首次使用，点击"配置密钥"输入阿里云API Key
3. 点击"重建索引"选择知识库目录
4. 点击"启动网页"开始使用

### 8.2 命令行模式

```bash
# 配置密钥
set DASHSCOPE_API_KEY=你的密钥

# 构建索引
python ingest.py --data_dir "D:\知识库资料"

# 启动问答
python main.py
```
