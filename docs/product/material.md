# Material: 多模态RAG知识库问答系统（ragku）

## 1. Overview

- 项目名称：基于阿里云通义千问的多模态RAG知识库问答系统（ragku）
- 核心能力：检索增强生成（RAG），将私有知识库与通义千问大模型深度结合，实现精准私域问答
- **最大亮点1：知识库随时切换** ——多个独立知识库，对话中传入 kb_id 即可动态切换，无需重启
- **最大亮点2：图片与视频均可分析** ——上传图片 OCR 识字、Qwen-VL 看图理解；上传视频自动抽取关键帧并交模型分析，结合知识库给出专业回答
- 技术栈：Python + FastAPI 后端，阿里云 DashScope（Qwen Turbo / Qwen-VL-OCR），NumPy 向量检索
- 部署形式：Web 网页服务 + 桌面启动器 EXE，开箱即用

## 2. Background

- 传统大模型知识截止，无法回答私有领域/实时业务问题
- RAG 方案价值：文档"即时注入"上下文，弥补通用 LLM 知识盲区
- 痛点深化：固定知识库灵活性差——本系统通过多知识库架构彻底解决
- 面向场景：企业内训、竞赛答辩、小团队私有知识管理、体育动作规范分析
- 参加全国大学生计算机设计大赛 AI 方向，面向实际落地场景设计

## 3. Key Info

### 核心功能模块
- **多知识库管理**：每个 KB 独立 ID、独立向量索引，互不干扰，任意创建删除
- **可切换资料库**：API 参数 kb_id 一键切换，毫秒级响应，无需重启服务
- **图片处理**：
  - OCR 识字：调用 Qwen-VL-OCR 提取图片中的文字，加入知识库可检索
  - 看图问答：上传图片 + 提问，Qwen-VL 分析画面内容，结合知识库综合回答
- **视频处理（重点差异化功能）**：
  - OpenCV 自动从视频中均匀抽取 4~8 个关键帧
  - 每帧转为 base64 图片，批量调用 Qwen-VL-Max 分析帧内容
  - 将帧分析结论与知识库 RAG 检索融合，输出专业回答
  - 支持体育动作规范性判断（"我的发球动作规范吗？"）
  - 最大支持 100 MB 视频文件
- **文件支持**：TXT、Markdown、PDF、DOCX、图片（JPG/PNG/WebP 等）、视频（MP4/AVI/MOV 等）
- **向量化进度监控**：实时 processed_chunks / total_chunks + 预计剩余时间
- **并发向量化**：最大并发 8，高效处理大量文档分片
- **检索策略**：余弦相似度 top-k，支持文件级过滤（selected_files 参数）

## 5. Analysis

- 对比固定知识库系统：本系统多 KB 隔离 + 随时切换，灵活性大幅领先
- 对比纯文本 RAG：图片 OCR + 视频关键帧分析，让多媒体内容同样可检索、可问答
- 对比全云端方案：本地部署 + 阿里云 API，数据安全与模型能力兼顾
- 核心竞争力矩阵：可切换知识库 × 图片/视频多模态 × 工程可靠（进度监控+断点续传）

## 6. Outlook

- 支持更多向量数据库后端（FAISS、Milvus）
- 引入重排序策略（re-ranking）提升检索精度
- 视频理解扩展：音频转文字（ASR）进一步丰富内容
- 支持知识库增量更新，避免全量重建索引
- 扩展为 SaaS 多租户平台
